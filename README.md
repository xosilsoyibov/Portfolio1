# Hosilbek Soyibov - Portfolio

Bu mening shaxsiy portfolio saytim.

## Tuzilma

- `index.html` — Asosiy portfolio sahifasi (bosh sahifa)
- `style.css` va `script.js` — Portfolio uchun stillar va skript
- `gul-olami/` — Gul do'koni loyihasi (alohida sahifa)

## GitHub Pages sozlash

1. Repository root'iga barcha fayllarni yuklang (hech qanday qo'shimcha papka ichida bo'lmasin).
2. Settings → Pages → Source: Deploy from a branch
3. Branch: main (yoki master)
4. Folder: / (root)

Asosiy link ochilganda Portfolio ochiladi.
"Loyihalar" bo'limidan "Gul Olami sayti" ni bosganda alohida sahifada gul do'koni ochiladi.
